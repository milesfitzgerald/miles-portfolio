# milesfitzgerald.com

Personal site of Miles Fitzgerald — Design Director at Microsoft.

One HTML file. One font file. Zero dependencies.

- **Live** — [milesfitzgerald.com](https://milesfitzgerald.com)
- **Type** — Instrument Sans, self-hosted variable woff2
- **Stack** — hand-built HTML & CSS, ~60 lines of vanilla JS (eased scroll, section reveals, copy-to-clipboard)
- Dark and light color schemes, AA contrast, `prefers-reduced-motion` aware

## Local dev

```bash
python3 -m http.server 8917
```

Deployed automatically by GitHub Pages on every push to `main`.
